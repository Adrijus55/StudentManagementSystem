# Student Management System

A console-based student management application developed in C#.

## Features

- View all students and their grades.
- Search for students by first and last name.
- Add new students.
- Add grades between 1 and 10.
- Remove students.
- Calculate student grade averages.
- Save student data to a text file and load it when the application starts.
- Validate user input and prevent duplicate student records.

## Technologies

- C#
- .NET
- Object-oriented programming (OOP)
- Lists and collections
- File handling
- Input validation

## Data Storage

Student records are stored in `Studentai.txt`.

Each record follows this format:

`FirstName;LastName;Grade1,Grade2,Grade3`

Example:

`Jonas;Jonaitis;8,9,10`

## How to Run

1. Open the solution in Visual Studio.
2. Build the project.
3. Run the application.
4. Use the console menu to manage student records.
